# All Stickers

أداة إنشاء وتصدير الملصقات ثلاثية الأبعاد (3D Sticker Studio) لتطبيق أندرويد بلغة Kotlin و Compose.

## الميزات الأساسية

- **استوديو النصوص ثلاثية الأبعاد**: إضافة طبقات نصية متعددة، تعديل الخط، الحجم، البعد، اللون، الخامة (ذهبي، فضة، كروم، نيون، إلخ)، الإضاءة، القاعدة، والخلفية.
- **تسجيل الحركة بالإصبع**: تفعيل وضع التسجيل ثم سحب النص ثلاثي الأبعاد أو النموذج ثلاثي الأبعاد مباشرة بالإصبع لتسجيل مفاتيح حركة تلقائية على الخط الزمني (مع إمكانية إضافة/مسح المفاتيح يدوياً).
- **تحريك الكاميرا عبر مسارات**: مسارات جاهزة (مدار، تمرير، تقريب، دائرة) وتسجيل حركة الكاميرا مباشرة أثناء التشغيل، مع مفاتيح كاميرا قابلة للانتقال والحذف من الخط الزمني.
- **ملصقات دون إنترنت**: أكثر من 50 ملصقاً مدمجاً داخل التطبيق (42 ملصقاً عادياً PNG + 14 نموذجاً ثلاثي الأبعاد GLB) موزعة على فئات، تعمل بالكامل بدون اتصال بالإنترنت.
- **التصدير**: تصوير المشهد (PNG)، تصدير GIF متحرك، وتصدير فيديو MP4 (H.264) مع تطبيق حركات النص والنموذج والكاميرا.
- **حفظ واستعادة المشاريع**: حفظ المشروع بشكل قابل للتعديل (طبقات، إطارات، حركات، كامات).

## كيفية إضافة الملصقات غير المتصلة (Offline Stickers)

الملصقات العادية (PNG) والنماذج (GLB) مضمّنة بالفعل داخل:

- `app/src/main/assets/stickers/images/`
- `app/src/main/assets/stickers/models/`
- `app/src/main/assets/stickers/catalog.json`

وتظهر كصور مصغّرة في قسم "الملصقات" داخل استوديو النصوص ثلاثية الأبعاد، وتُضاف للمشهد مباشرة بدون إنترنت.

لإضافة المزيد: ضع الملف الجديد في المجلد المناسب وسجّله في `catalog.json` مع `type` = `NORMAL_IMAGE` أو `MODEL_3D`، ومسار `assetPath` وصورة مصغّرة اختيارية `previewAssetPath`.

## بناء ملف APK (حصراً عبر GitHub Actions)

بموجب متطلبات المشروع، لا يُبنى التطبيق محلياً (لا JDK، لا Android SDK، لا تعديلات على إعدادات النظام). يتم بناء ملف APK حصراً عبر **GitHub Actions** عند كل دفع (push) إلى فرع `main` أو يدوياً عبر `workflow_dispatch`.

خطوات النشر:

1. ارفع المشروع إلى مستودع GitHub ( الفرع `main` ):
   ```bash
   git add .
   git commit -m "feat: complete 3D sticker studio with offline stickers, camera paths and GIF/MP4 export"
   git push origin main
   ```
2. سيشتغل workflow `.github/workflows/build.yml` تلقائياً ويقوم ب:
   - تنصيب Java 17
   - تنصيب Android SDK
   - بناء ملف `app-debug.apk`
   - تشغيل اختبارات وحدة مختارة
   - رفع الملف كمرفق (artifact) وإنشاء إصدار (release) على GitHub

ملف APK الناتج يكون في:
`app/build/outputs/apk/debug/app-debug.apk`

## طريقة تسجيل الحركة

1. من قسم "الحركة" اختر الهدف: النص أو النموذج 3D.
2. فعّل "السحب مفعّل" و"تسجيل الحركة أثناء السحب".
3. شغّل الخط الزمني ثم اسحب العنصر بإصبعك؛ تُسجَّل مفاتيح الحركة تلقائياً.
4. من قسم "الكاميرا" يمكنك اختيار مسار جاهز أو تفعيل "تسجيل حركة الكاميرا" أثناء التشغيل.
5. من قسم "المشروع" صدّر GIF أو MP4.

## ملاحظات حول الترميز (GIF / MP4)

- **GIF**: يُترمّز داخل التطبيق باستخدام مشفر GIF نقي بلغة Kotlin (لا يعتمد على مكتبات خارجية).
- **MP4**: يُستخدم `MediaCodec` + `MediaMuxer` الخاص بنظام أندرويد لترميز frames المشهدة إلى فيديو H.264.
- يُسجل التصدير 장면 الاستوديو أثناء تشغيل الخط الزمني، لذا يُنصح بتفعيل مسار الكاميرا أو حركة الطبقات قبل بدء التصدير للحصول على متحرك متكامل.

## القيد على بيئة البناء

هذا المشروع مُصمم للبناء حصرياً عبر GitHub Actions. environment المحلي لا يحوي JDK ولا Android SDK ولا يُسمح بتثبيتهما أو تعديل إعدادات النظام为此 الغرض.
